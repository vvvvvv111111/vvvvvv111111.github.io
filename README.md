# Портфолио vvvvvvvvvwwwww

Сайт: https://vvvvvvvvvwwwww.online

Весь контент сайта — тексты, цены, услуги, Discord и работы — лежит в одном файле **`content.js`**.
Картинки работ — в папке **`works/`**. Файл `index.html` (код сайта) менять не нужно.

Все правки можно делать прямо на сайте GitHub, ничего не устанавливая. После сохранения сайт обновляется сам через 1–2 минуты.

---

## Как отредактировать `content.js` на GitHub

1. Открой репозиторий на GitHub и нажми на файл `content.js`.
2. Нажми на значок карандаша ✏️ справа сверху («Edit this file»).
3. Поменяй что нужно (только текст в кавычках и числа).
4. Нажми зелёную кнопку **Commit changes…** → ещё раз **Commit changes**.

> ⚠️ Не удаляй кавычки `" "`, запятые `,` и скобки `{ } [ ]` — из-за этого сайт перестанет показывать контент.
> Если что-то сломалось — на GitHub есть история изменений файла (кнопка **History**), можно вернуть прошлую версию.

## Добавить работу из Figma

**1. Экспорт из Figma**
- Выдели фрейм → справа внизу панель **Export** → нажми **+**.
- Формат **PNG** (или **JPG**, если картинка тяжёлая), размер **2x**.
- Нажми **Export** и сохрани файл.
- Назови файл латиницей, без пробелов: `shop-ui.png`, `inventory-1.png`, `inventory-2.png`.

**2. Загрузка на GitHub**
- В репозитории открой папку `works`.
- Нажми **Add file → Upload files**, перетащи картинки, нажми **Commit changes**.

**3. Добавление в `content.js`**
Найди раздел `projects: [ ... ]` и добавь новый блок после последнего — **не забудь запятую** после предыдущего `}`:

```js
  projects: [
    {
      title: "Quiz interface",
      ...
      images: ["works/quiz-interface.jpg"]
    },                                         // ← запятая!
    {
      title: "Shop UI",                        // название
      category: "Simulator",                   // раздел для фильтра
      type: "Game UI",                         // подпись под карточкой
      description: "Shop for a pet simulator", // описание (можно "")
      cover: "works/shop-ui.png",              // картинка на карточке
      images: ["works/shop-ui.png", "works/shop-ui-2.png"]   // все картинки проекта
    }
  ]
```

- Новые разделы фильтра (`category`) появляются сами.
- Если у проекта несколько картинок — по клику открывается просмотр, листается стрелками.
- Порядок блоков = порядок на сайте. Самую сильную работу ставь первой.

**Удалить работу** — удали её блок `{ ... }` вместе с запятой перед ним.

## Поменять цену

```js
  services: [
    {
      name: "Per frame",
      description: "",
      prices: { Robux: 3000, USDT: 20, RUB: 1500 }
    }
  ]
```

Просто поменяй числа. Если какую-то валюту в услуге не нужно показывать — удали её из `prices`.

## Добавить услугу

Скопируй блок услуги целиком, вставь после него через запятую и поменяй:

```js
  services: [
    {
      name: "Per frame",
      description: "",
      prices: { Robux: 3000, USDT: 20, RUB: 1500 }
    },
    {
      name: "Full UI pack",
      description: "Main menu, shop, inventory and settings",
      prices: { Robux: 12000, USDT: 80, RUB: 6000 }
    }
  ]
```

## Добавить или убрать валюту

В строке `currencies: ["Robux", "USDT", "RUB"]` — это кнопки над ценами.
Новую валюту добавь и туда, и в `prices` у каждой услуги — с тем же написанием (например, `"USD"`).

## Поменять Discord

```js
  discord: {
    username: ".dinastyy",   // ник — копируется по клику
    link: ""                 // ссылка на профиль или сервер, например "https://discord.gg/xxxx"
  },
```

Если указать `link`, рядом с карточкой появится кнопка-стрелка, открывающая ссылку.

## Поменять описание и тексты

- `about` — текст в блоке «Behind the pixels». Новая строка внутри текста — `\n`.
- `role`, `heroTitle`, `heroTitleSoft`, `heroSub` — надписи на первом экране.
- `logo` — большой логотип сверху.
