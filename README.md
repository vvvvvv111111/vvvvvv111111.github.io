# Портфолио vvvvvvvvvwwwww

Сайт: https://vvvvvvvvvwwwww.online

## Как менять сайт — режим владельца (Owner access)

Внизу сайта, в правом углу футера, есть кнопка **Owner access**. Она открывает редактор прямо на сайте:

- **Работы** — добавить работу, перетащить картинки из Figma, поменять название, раздел, описание, порядок работ и картинок, выбрать обложку, удалить.
- **Цены и услуги** — поменять цены, добавить или удалить услугу, добавить или убрать валюту.
- **Профиль** — тексты первого экрана, описание «обо мне», ник и ссылка Discord.

Все изменения сразу видны на странице. Кнопка **«Сохранить на сайт»** публикует их — через 1–2 минуты сайт обновится для всех.

Можно открыть редактор и по прямой ссылке: `https://vvvvvvvvvwwwww.online/#owner`

### Первый вход: токен GitHub (один раз)

Редактор сохраняет изменения в этот репозиторий, поэтому ему нужен ключ доступа:

1. Открой https://github.com/settings/personal-access-tokens/new
2. **Token name** — любое, например `portfolio`. **Expiration** — 1 год или дольше.
3. **Repository access** → **Only select repositories** → `vvvvvv111111.github.io`.
4. **Permissions** → **Add permissions** → **Contents** → **Read and write**.
5. Нажми **Generate token**, скопируй ключ (`github_pat_…`) и вставь его в окно Owner access.

Ключ хранится только в твоём браузере («Запомнить на этом устройстве»). Никому его не показывай. Если ключ истёк или потерялся — создай новый тем же способом. Кнопка «Выйти» в редакторе удаляет ключ с устройства.

### Картинки из Figma

- Выдели фрейм → панель **Export** справа внизу → **PNG**, размер **2x** → **Export**.
- В редакторе открой работу и перетащи файлы в поле «Перетащи сюда картинки».
- Большие картинки редактор сам сжимает в WebP без заметной потери качества.
- Первая картинка — обложка на карточке. Звёздочка ★ делает картинку обложкой, стрелки меняют порядок.

## Вручную, без редактора

Весь контент лежит в файле `content.js`, картинки — в папке `works/`. Файл можно открыть на GitHub, нажать на карандаш ✏️, поменять текст или числа и нажать **Commit changes**.

Не удаляй кавычки `" "`, запятые и скобки `{ } [ ]`. Если что-то сломалось — на GitHub у файла есть **History**, там можно вернуть прошлую версию.

## Файлы

- `index.html` — сам сайт (дизайн, анимации).
- `owner.js` — редактор Owner access.
- `content.js` — весь контент.
- `works/` — картинки работ.
- `CNAME` — домен `vvvvvvvvvwwwww.online`, не трогать.
